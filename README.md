# Tripefy 制谱器

独立的网页制谱器。React、Vite、shadcn/ui 与 Canvas 2D；不依赖 Godot 运行。

## 启动

安装 Node.js 22.14 或更新版本，然后克隆仓库：

```sh
git clone git@github.com:yemaster/tripefy-maker.git
cd tripefy-maker
npm start
```

浏览器打开 `http://127.0.0.1:8770/`。仓库包含 `dist/` 构建产物，直接使用无需安装依赖或 Godot。

开发时先执行 `npm ci`，再执行 `npm run dev`，浏览器打开终端显示的本地地址。`npm test` 运行检查，`npm run build` 更新 `dist/`；提交构建产物后，其他设备拉取即可使用。

本目录可以单独移动。`.gdignore` 仅用于放在 Godot 项目内时跳过扫描，不影响独立运行。

## 换设备继续制谱

谱面自动保存和音频缓存属于当前浏览器，不会随 Git 同步。换设备前导出 `.chart.json`，并通过音频旁的“另存”保存原音频；在另一台设备分别导入这两个文件。保留音频文件名与谱面中的 `audio` 一致。

更新制谱器可执行 `git pull`，然后重新启动 `npm start`。自动保存仍属于原浏览器和本地地址，正式谱面请保留导出的文件。

## 制谱

- 默认使用选择工具：在空白处拖动框选，拖动已选音符可整体移动；Ctrl / Cmd / Option / Shift + 单击增减选择，按住这些键拖框可追加选择。Option / Alt 在选择工具中用于多选，在放置工具的空白处或开始拖动后按下仍用于临时取消吸附。
- 按 2 切换单键工具，在旁边选择 Tap、Drag 或 HearTap 后单击放置；按 3 切换 Hold 工具，按下确定头部并向上拖出尾部。按 1 返回选择工具，按 4 切换擦除工具。选中音符后可在左侧修改类型，支持多选转换和撤销。
- 单选 Hold 后，双击身体添加路径节点，拖动圆点调整节点的位置和时间。左侧也可添加、选择节点并输入数值；“节点时间”是相对 Hold 头部的秒数。
- Hold 起点固定在 0 秒，终点随长按长度变化，首尾节点不能删除。新路径默认平滑，连续转向且不越过节点；旧 Hold 可点击「平滑曲线」整条转换，支持撤销。单个节点也可选线性、缓入、缓出、缓入缓出，控制从前一个节点到该节点的形状。拖动尾端可调整长按长度。
- Hold 内部节点显示高亮横条，相邻节点之间各算一段；头部和尾端不额外计分。Drag 是稍薄的青玉横条，HearTap 是淡紫横条。
- 左侧音符属性提供透明度（0–100%）和速度（0.1–8×），可对多选音符批量修改；时间、位置、长度只在单选时编辑。水平翻转同时翻转 Hold 路径。
- 吸附的 `1 / n` 表示每拍 n 等分，包含 3、5、7。自定义支持 1–64 等分，跨 1、2、4 拍。Alt 临时关闭吸附。
- 横向可选自由位置、4K / 5K / 6K / 7K / 8K / 9K，以及原有 1/8、1/16、1/32 等分。K 模式显示轨道编号和参考线，放置、拖动与 Hold 节点吸附到轨道中心；Alt 临时自由移动。切换预设不会重排现有音符，需调整时选中后点击「对齐轨道」，支持撤销。整组拖到边缘时保留完整轨道间距。预设作为本机编辑偏好保存，导出仍使用 0–1 的无轨坐标。
- 鼠标滚轮按屏幕距离前后移动时间，放大后时间步长自动减小；Shift + 滚轮为四分之一速度精调。Ctrl / Cmd + 滚轮缩放，暂停编辑时保留鼠标下方的时间位置；点击缩放百分比恢复 100%。↑ / ↓ 或底部上一格／下一格按当前吸附定位，Shift + ↑ / ↓ 逐拍定位，滚动后仍对齐真实节拍格。底部进度条可拖动定位，时间框可输入秒数或 `mm:ss.mmm` 后回车。
- Space 播放/暂停；支持 0.25×、0.5×、0.75×、1×、1.25×、1.5×、2×。
- Ctrl+C/V 复制粘贴，Ctrl+X 剪切，Ctrl+A 全选；Ctrl+M 左右镜像，Ctrl+Shift+V 镜像粘贴；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，Delete 删除。顶部提供有文字标识的框选、复制、粘贴、镜像，左侧音符页提供全选、剪切、镜像粘贴和对齐轨道。粘贴定位到当前播放时间，保留整组相对节奏与位置；镜像同时翻转 Hold 路径和绑定的位置事件，镜像粘贴保留原剪贴板，后续普通粘贴仍为原方向。
- 可载入 MP3、OGG、WAV。谱面自动存于当前浏览器；最近音频缓存于 IndexedDB。

## 操作区

左侧分为「谱面」「音符」「分组」「事件」「预设」：曲目信息、节拍、音频与场景放在谱面页；选中音符后自动显示音符属性和 Hold 节点；事件参数位于事件列表上方。切换属性页会回到顶部，保留当前选择。

画布上方第一行是编辑工具、复制粘贴、镜像、撤销重做与编辑／预览切换，第二行是节拍吸附、横向轨道、分组筛选、网格和缩放。底部仅保留进度条与播放控制，包含逐格定位、片段循环、时间、节拍器、打击音、播放倍速和音量。

## 分组、预设与片段检查

- 选中音符后，在「分组」点击「选中音符成组」，或按 Ctrl / Cmd + G；Ctrl / Cmd + Shift + G 取消所选音符的分组。可以新建空组、改名、移动成员、选择成员、复制及解散。解散保留音符，移除该组的基础属性和组事件，支持撤销。
- 眼睛和锁仅控制编辑状态；预览与游戏仍播放完整谱面。顶部「分组」筛选用于单独编辑一组；框选、全选、擦除会跳过隐藏或锁定组。锁定不阻止全局事件影响该组。
- 组的横向偏移、透明度、速度是组内所有音符的基础属性。复制音符会一并复制它们所在组及组事件；整组移动时组事件一起移动；局部镜像会分离出独立组，避免影响未选音符。
- 「预设」内置渐入、渐出、明暗呼吸、向左／向右移动、左右摆动、加速、减速、减速回归。选择目标后按拍设置长度与强度；「重复与叠加」提供重复次数、逐音符错开、事件层和冲突替换。默认从当前时间开始，也可将整个动画结束点对齐各音符的到达时刻；这种模式不使用错开参数。
- 预设从当前通道状态开始，重复段连续衔接。渐入恢复到 100% 通道透明度，渐出降到 0；已完全显示时渐入不会先闪灭。呼吸、摆动和减速回归返回应用前的通道值；减速从当前速度降低。向左／向右移动按相对变化量写入，不再先瞬移到侧边。强度 0 保持当前值。
- 应用预设生成普通事件，可继续编辑、复制、删除和撤销。冲突默认拒绝整次操作；勾选替换才删除同层冲突事件。新旧事件不能超出歌曲时间。
- 同目标的所选事件可按拍长比例存为命名预设，跨 BPM 变速点也保留节拍比例及终值／变化量模式；支持改名、删除、预设库 JSON 导入／导出。自定义预设也随谱面保存；预设库导入合并，保留已有内容。
- 画布与事件列表统一支持 Ctrl / Cmd / Option / Shift 增减选择，框选可以同时选中音符和事件；事件页 Ctrl / Cmd + A 全选当前筛选内的事件。可跨层选择（层筛选选「所有层」）、批量缓动、平移时间、转移事件层、复制粘贴和删除。拖动已选事件标记整体移动；快捷键与音符剪贴板共用，混合选择时复制、剪切、粘贴、整体拖动与删除同时处理音符和事件，关联事件不重复复制。
- 「谱面 → 节拍 → BPM 变速点」添加、修改、删除多段 BPM。3/5/7 等分网格、逐格定位、节拍器与预设长度均随 BPM 变化；已写入的音符秒数不随之移动。
- 播放键旁的循环按钮设置 A/B，可用「当前」标记边界；启用后在片段内循环，支持倍速。循环范围标在唯一的进度条上；它是本次编辑会话的状态，不改变导出谱面。

## 事件与预览

左侧“事件”页可添加速度、位置、透明度事件。目标可选全部音符、一个分组或某一个音符；添加时优先使用明确的目标筛选，其次使用单选音符、当前事件或当前分组。每个目标有四层事件，可按目标和层筛选。在同一时刻继续添加时，会优先选择尚未被占用的属性通道。点击列表或画布左侧的事件标记可选择事件，拖动标记可调整开始时间。

事件只需设置开始时间、持续时间、插值，以及「终值」或「变化量」。起点自动继承同目标、同层、同属性的前一段终值；首段位置从 0 开始，速度／透明度从 1 开始。修改、移动或删除前段时，后段起点随之更新。「变化量」是加减量，例如速度从 1.5× 减少 0.5 得到 1×，透明度从 60% 减少 20 得到 40%。侧边栏只读显示实际起点与终点。旧谱显式起点保留以避免改动已有演出，编辑该事件后转为自动衔接。事件时间使用有效播放秒数，包含谱面偏移；持续时间为 0 时立即切换到结束值。事件结束后保留结束值，直到同一目标、同一层、同一属性的后续事件生效。该通道内的事件不能重叠。

| 属性 | 数值 | 含义 |
| --- | --- | --- |
| 速度 | 0.1–8× | 下落速度倍率，不改变音符判定时间 |
| 位置 | −100–100% | 相对横向偏移；0% 不移动，10% 向右移动场宽的 10% |
| 透明度 | 0–100% | 0% 为不可见，100% 为完全显示 |

全局、分组、单音符各层的速度、透明度事件和基础值相乘；位置事件与基础位置、Hold 路径相加，最终限制在画面范围内。复制、移动、翻转和删除音符时，会同时处理绑定到这些音符的事件；未选中的全局事件保持独立。

“编辑”使用线性时间网格，便于吸附、框选和精确拖动；不把速度和位置事件烘入编辑坐标。低透明度音符仍保留可见轮廓。“预览”应用音符速度、透明度、Hold 路径及事件，配合播放或定位检查实际效果。速度事件沿用游戏端的分段多项式积分，按通道缓存；修改、撤销或拖动事件后重新计算，降低多段 Hold 的逐帧计算量。制谱窗口保持 2D 坐标。

## 导出与游戏接入

导出 `.chart.json`，把音频原文件放在同一目录。JSON 记录音频相对文件名，不嵌入音频；“另存”可下载已载入的原文件。网页中的音频和谱面都在浏览器本地处理。

JSON 格式：`format: "tripefy.chart"`。普通谱面导出 `version: 1`；包含分组或第 2–4 层事件时导出 `version: 2`，需使用同步更新后的游戏端。旧版谱面仍可导入。元信息位于 `metadata`，音符位于 `notes`。音符包含 `type`（`tap / hold / drag / heartap`）、`time`（秒）、`x`（0–1）、`duration`（秒）。只有 Hold 的长度大于 0。旧文件省略类型时按长度推断 Tap / Hold。实际判定时间为 `time + offset`。

扩展音符字段为 `opacity`（0–1，默认 1）、`speed`（0.1–8，默认 1）和 `path`。Hold 的 `path` 是按时间递增的 `{ time, x, curve }` 列表，时间相对头部，从 0 到 `duration`；起点 x 必须与音符 x 一致。路径额外支持 `curve: "smooth"`（保形三次 Hermite 插值），需要同步更新游戏端。旧谱面没有路径时，自动补为等宽直线 Hold。

事件位于 `events`，每项包含 `{ id, target, property, time, duration, from, to, curve }`。`target` 为 `all`、分组 ID 或音符 ID；`property` 为 `speed / x / opacity`；事件实际开始时间同样为 `time + offset`。界面以百分比显示的位置与透明度，在 JSON 中分别存为 −1–1 和 0–1，例如位置 10% 存为 0.1。`curve` 支持 `linear / easeIn / easeOut / easeInOut`。旧谱面缺少 `events` 时按空列表处理。

`scene.preset` 为 `dusk / night / clear / overcast`。作者在制谱器中设定，游戏玩家不能切换。`beatsPerBar` 只控制编辑器小节线，不改变音符实际时间。

在单独的 Tripefy 游戏项目中，Godot 场景的 `chart_path` 指向谱面，或启动时传入 `-- --chart=绝对路径`。完整格式见本仓库的 [谱面格式](docs/chart-format.md)。

## 参考

操作区划分参考 [osu! 编辑器](https://osu.ppy.sh/wiki/en/Client/Beatmap_editor) 与 [时间轴](https://osu.ppy.sh/wiki/en/Client/Beatmap_editor/Timelines)，吸附、选择与音频校时参考 [ArrowVortex 官方指南](https://arrowvortex.ddrnl.com/guide.html)，事件类型、列表与参数分区参考 [ArcadeZero 场景控制文档](https://github.com/Tempestissiman/ArcadeScenecontrol#the-editing-window)。底部提供单一进度条。分层事件、批量操作与片段检查对照 [Phiedit 2573](https://github.com/Chengxuxiaoyuan-2573/Phiedit-2573) 的[操作说明](https://github.com/Chengxuxiaoyuan-2573/Phiedit-2573/blob/master/introduction.md)（Ctrl 增选、空白框选、事件与音符共用剪贴板），以及 [Kipphi Apparatus](https://github.com/TeamZincs/kipphi-apparatus) 的事件分层、多选编辑功能。这里借鉴工作流程，保留 Tripefy 固定判定线的玩法；不导入 RPE 谱面或复制其多判定线、父子线与 shader 系统。

界面组件通过 [shadcn/ui 官方 CLI](https://ui.shadcn.com/docs/installation/vite) 安装，使用原生 Neutral 主题，源文件位于 `src/components/ui`；图标来自 Lucide。没有自定义字体或组件样式覆盖。

## 验证

`npm test` 覆盖 JSON 往返、非法数据、3/5/7 等分、跨拍连音、撤销重做、路径框选、组复制、附属事件、速度积分、路径投影和打击特效时序。滚轮测试包含 55–220% 缩放、鼠标与触控板、行／页单位、精细滚动和鼠标位置缩放；速度计算与独立积分算法交叉验证。

浏览器检查：先 `npm run build`，再运行 `npm run test:browser`。需要本机已有 Playwright 与 Chromium（可临时安装 `npm install --no-save --package-lock=false playwright`，再执行 `npx playwright install chromium`）。已有独立测试运行时可用 `PLAYWRIGHT_MODULE` 指定 Playwright 包路径、`PLAYWRIGHT_CHROMIUM` 指定浏览器路径。测试使用临时本地服务和独立浏览器环境，检查滚轮、实际放置与框选、Hold 节点、事件、音频、倍速、下载及重新导入；新增检查覆盖分组锁定／筛选／复制、内置与自定义预设、多层事件剪贴板、BPM 变化、循环、自动保存恢复与 v2 导出；截图与结果存入忽略提交的 `.preview/editor-update/` 和 `.preview/authoring/`。布局检查覆盖 1440×900、1280×720、1024×768。

`tests/fixtures/ui-export.chart.json` 与 `animation-ui-export.chart.json` 是从浏览器实际导出的测试谱，后者包含路径编辑、事件和多选复制结果。合成测试音频与说明位于 [tests/fixtures](tests/fixtures/README.md)。

与 Godot 的端到端判定及动画数值对照测试位于单独的 Tripefy 游戏项目，不是运行本仓库测试的依赖。
